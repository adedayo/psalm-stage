## Built for Sunday Morning Reliability

<CardGrid>
  <Card title="Zero-Latency Native Audio Core" icon="rocket">
    Written in Rust (`psalm-audio-core`). At native tempo and key, audio streams bit-perfect with zero spectral latency. When transposing or stretching tempo, click and cues stay sample-locked frame-for-frame.
  </Card>
  <Card title="Universal Split L/R & Multi-Out" icon="setting">
    Run on any 2-channel USB interface (Left = FOH Music, Right = IEM Click + Cues) or expand to multi-output interfaces (18i20, X32/M32, Dante) with per-bus routing.
  </Card>
  <Card title="Live Stage, Loops & Tonic Pads" icon="star">
    Jump quantized sections on the fly, arm infinite loops for ministry moments, blend multi-layer 12-key ambient pads, and layer live Afrobeat, Makossa, Woro, Funk, or Worship percussion grooves.
  </Card>
  <Card title="MIDI Pedalboards, Workbench & AI" icon="laptop">
    Plug-and-play Omni MIDI with 1.5s hotplug, one-click MIDI Learn, built-in Import Workbench for song stems, and a headless CLI + MCP server for AI-assisted Sunday setlist planning.
  </Card>
</CardGrid>
