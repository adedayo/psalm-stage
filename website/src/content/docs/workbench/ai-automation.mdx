Every desktop release of Psalm Stage bundles **`psalm-stage-cli`**, a headless CLI and **Model Context Protocol (MCP)** stdio server (`psalm-stage-cli mcp`) built on `psalm-workbench`.

## What AI Assistants Can Do with Psalm Stage

When connected via MCP (e.g., in Claude Desktop, Antigravity, Cursor, or VS Code), your AI assistant can:

- Check installed workbench toolchain status (`get_toolchain_status`)
- Search and fuzzy-match songs in your local library (`list_library_songs`, `match_library_song`)
- Search YouTube reference tracks (`search_youtube_tracks`)
- Plan a Sunday setlist with automatic key-shift / harmonic transition calculations (`plan_sunday_setlist`)
- Ingest local or YouTube audio into song bundles (`ingest_song`, `ingest_songs_batch`)
- Save and inspect Sunday setlists (`create_or_update_setlist`, `list_setlists`, `get_setlist`)

<Aside type="caution">
  **Live Lock Protection**: When **Live Lock** is enabled in the desktop app during a service, external setlist sync is suppressed so nothing modifies your live stage state mid-worship.
</Aside>

## Quick Setup for MCP Clients

Open **Setlist Studio → AI Harness Setup** inside Psalm Stage to copy your pre-filled MCP JSON config (pointing directly to your bundled `psalm-stage-cli` binary), or configure your MCP client manually:

```json
{
  "mcpServers": {
    "psalm-stage": {
      "command": "/path/to/psalm-stage-cli",
      "args": ["mcp"]
    }
  }
}
```

## Headless CLI Commands

You can also script `psalm-stage-cli` directly from your terminal:

```bash
# Inspect toolchain & library readiness
psalm-stage-cli status --json
psalm-stage-cli library list --status ready --json

# Plan & build a Sunday setlist from a JSON song list
psalm-stage-cli setlist plan --input sunday.json --json
psalm-stage-cli setlist build --input sunday.json --name "Sunday Morning" --auto-approve --json

# Generate percussion kits and export 9-stem loop bundles
psalm-stage-cli loop kit generate --profile studio --json
psalm-stage-cli loop export --title "Praise Groove" --style Afrobeat --bpm 124 --bars 16 --json
```
