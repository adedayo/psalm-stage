Psalm Stage ships as standalone, self-contained desktop installers from [GitHub Releases](https://github.com/adedayo/psalm-stage/releases). Worship leaders, musicians, and sound techs do **not** need Node.js, Rust, or any coding tools.

## Choose Your Platform

<Tabs>
  <TabItem label="macOS (Fastest 1-Line Install)">
    Because Psalm Stage is distributed free and open source without a paid Apple Developer subscription, macOS Sequoia attaches a browser quarantine flag to manually downloaded `.dmg` files.

    The one-line installer automatically detects Apple Silicon (`M1`–`M4`) or Intel, downloads the latest `.dmg` from GitHub Releases, installs **Psalm Stage.app** into `/Applications`, and clears the quarantine flag:

    ```bash
    curl -fsSL https://raw.githubusercontent.com/adedayo/psalm-stage/main/install.sh | bash
    ```
  </TabItem>
  <TabItem label="macOS (.dmg Manual Install)">
    1. Download the `.dmg` for your Mac from [GitHub Releases](https://github.com/adedayo/psalm-stage/releases/latest):
       - **Apple Silicon (M1 / M2 / M3 / M4)**: `Psalm-Stage_<version>_aarch64.dmg`
       - **Intel Mac**: `Psalm-Stage_<version>_x64.dmg`
    2. Open the `.dmg` and drag **Psalm Stage** into **Applications**.
    3. Double-click **Psalm Stage**. If macOS shows *"cannot be opened because it is from an unidentified developer"*:
       - Click **Done**.
       - Open **System Settings → Privacy & Security**, scroll to **Security**, and click **Open Anyway**.
       - Confirm with Touch ID or your password. macOS remembers this permanently.
  </TabItem>
  <TabItem label="Windows 10 / 11">
    1. Download `Psalm-Stage_<version>_x64-setup.exe` (or the `.msi` installer) from [GitHub Releases](https://github.com/adedayo/psalm-stage/releases/latest).
    2. Double-click the installer.
    3. If **Windows Defender SmartScreen** shows *"Windows protected your PC"*, click **More info** → **Run anyway**.
    4. Follow the installer prompts. A Start Menu and desktop shortcut are created automatically.
  </TabItem>
  <TabItem label="Linux">
    Download either the `.AppImage` or `.deb` package from [GitHub Releases](https://github.com/adedayo/psalm-stage/releases/latest):

    - **AppImage**:
      ```bash
      chmod +x Psalm-Stage_*.AppImage
      ./Psalm-Stage_*.AppImage
      ```
    - **Debian / Ubuntu (`.deb`)**:
      ```bash
      sudo apt install ./Psalm-Stage_*.deb
      ```
  </TabItem>
</Tabs>

## Automatic Update Banner

When your laptop is connected to Wi-Fi, Psalm Stage checks [GitHub Releases](https://github.com/adedayo/psalm-stage/releases) on startup and shows a non-intrusive banner at the top of the window when a newer version is available.

<Aside type="tip" title="Stage Safe by Design">
  The update banner is **automatically suppressed during live playback** and when offline on Sunday mornings so it never interrupts a service.
</Aside>

## Optional Audio Prep Tools

The **Live Stage**, **Setlist Studio**, **Tonic Pad Player**, and **Loop Studio** work 100% out of the box with zero extra software. If you plan to download YouTube reference tracks or split stems locally in **Import Workbench**, see the optional toolchain instructions in [Import Workbench & Song Bundles](/psalm-stage/workbench/import-and-stems/).
